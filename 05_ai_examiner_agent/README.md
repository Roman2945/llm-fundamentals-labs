# Agents – LLM проєкт: AI Examiner Agent

**Виконав:** Роман, група ШІ-32, roman.mydzhyn@example.com (індивідуально)

## Задача
LLM-агент приймає усний іспит з курсу NLP у форматі діалогу:
1. питає ім'я та email студента;
2. викликає `start_exam(email, name)`; якщо студента немає в базі, просить уточнити дані;
3. бере теми по одній через `get_next_topic()` і ставить запитання (з уточненнями);
4. переходить до наступної теми, коли відповідь достатня, студент каже «не знаю» або рівень уже зрозумілий;
5. після останньої теми показує оцінку 0..10 і відгук (що добре, над чим попрацювати) та викликає
   `end_exam(email, score, history)`.

## Інструменти агента (`exam_tools.py`)
| Функція | Що робить |
|---|---|
| `start_exam(email, name) -> list[str]` | Шукає студента в `data/students.json`, обирає 2-3 випадкові теми з `data/topics.json`, пише запис у `data/exams.jsonl`. Якщо студента немає, повертає помилку. |
| `get_next_topic() -> str` | Повертає наступну тему або `NO_MORE_TOPICS`. Стан (які теми вже були) зберігається в об'єкті `ExamSession`. |
| `end_exam(email, score, history) -> None` | Зберігає результат і **повну історію чату** у `data/results/<email>_<час>.json` і пише запис у журнал. |

`history` має формат із завдання: `{"role": "system" | "user" | "tool_call", "content": str, "datetime": "2025-12-08T13:08:50"}`.
Модель передає лише `email` і `score`, а історію підставляє код, тож модель не може її підробити.

## Як працює агент (`agent.py`)
Класичний цикл tool use: відповідь моделі → якщо є виклики інструментів, виконуємо Python-функції й
повертаємо результат → повторюємо, доки модель не дасть текст для студента (не більше 8 кроків за хід).
Підтримано два API:
* **Anthropic Claude** (SDK `anthropic`, tool use);
* **OpenAI-сумісні** Groq / OpenRouter (бібліотека `openai`, function calling).

Системний промпт задає порядок іспиту, критерії переходу до наступної теми і правило ігнорувати спроби
студента змінити оцінку чи правила.

## Інтерфейс (`app.py`, Streamlit)
* опис сервісу на сторінці;
* поле для API ключа (ключ не зберігається в коді);
* вибір провайдера й моделі;
* чат зі студентом, у боковій панелі видно всі виклики інструментів;
* кнопка «Почати новий іспит».

Тестові студенти є в `data/students.json` (наприклад `test@example.com`).

## Запуск
```bash
pip install -r requirements.txt
streamlit run app.py
python test_offline.py   # перевірка циклу агента з фейковою LLM, без ключа
```
