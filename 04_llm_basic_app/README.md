# LLM проєкт (базовий рівень): Текстовий помічник

**Виконав:** Роман, група ШІ-32, roman.mydzhyn@example.com

## Задача
Вебзастосунок, який робить **один виклик LLM** і повертає лише результат. Підтримує чотири задачі:

| Задача | Що робить |
|---|---|
| Сумаризація | 2-5 речень з головними думками тексту |
| Зміна стилю | офіційний, розмовний, простими словами, науковий, дружній лист |
| Виправлення граматики | орфографія, граматика, пунктуація без зміни змісту |
| Переклад | українська, англійська, польська, німецька, французька, іспанська |

## Як забезпечено «лише результат»
1. Системний промпт прямо забороняє вступи («Ось переклад…», «Звичайно…»), пояснення й лапки.
2. Текст користувача передається між тегами `<text></text>` і позначений як дані, а не інструкції
   (захист від того, що модель почне виконувати команди з самого тексту).
3. Функція `clean()` прибирає вступну фразу чи теги, якщо модель усе ж їх додала.

## Мовна модель
Провайдер обирається в боковій панелі, ключ API вводиться в поле (у коді не зберігається):
* **Groq** (безкоштовний доступ): `llama-3.3-70b-versatile`, `openai/gpt-oss-120b` та ін.
* **OpenRouter**: безкоштовні моделі з суфіксом `:free`.
* **Anthropic Claude**: `claude-haiku-5-5` (найдешевша), `claude-sonnet-5-5`, `claude-opus-5-5`.

Groq та OpenRouter мають OpenAI-сумісний API, тому викликаються бібліотекою `openai`;
Claude викликається офіційним SDK `anthropic` (`llm.py`).

## Запуск локально
```bash
pip install -r requirements.txt
streamlit run app.py
```
Відкрийте http://localhost:8501, оберіть провайдера, вставте ключ і текст.
