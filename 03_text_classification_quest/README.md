# Text Classification Quest (fine-tuning BERT)

**Виконав:** Роман, ШІ-32, roman.mydzhyn@example.com

* Дані: 10 000 англомовних відгуків (бінарна тональність), valid 1 000, test 9 216 (= картинка 96×96).
* Модель: `answerdotai/ModernBERT-base`, дотренування через HuggingFace `Trainer` на GPU T4:
  2 епохи, lr 2e-5, batch 16, max_len 256, fp16. Час тренування 6.4 хв.
* Якість на валідації: **accuracy 0.962, F1 0.962**.
* Передбачення тесту → пікселі (позитив білий, негатив чорний): на малюнку **ракета** (`quest_image_modernbert.png`).
* `lab.answer("rocket")` → **«Відповідь правильна ✅ Вірно! Лаба зараховується»**.

## Додаткове завдання: логістична регресія
| Модель | accuracy (valid) | F1 (valid) | тренування | передбачення test |
|---|---|---|---|---|
| ModernBERT-base | 0.962 | 0.962 | 383 с (GPU) | 65.6 с |
| TF-IDF (1-2 грами) + LogisticRegression | 0.865 | 0.865 | 3.7 с (CPU) | 1.2 с |

ModernBERT точніший приблизно на 10 п.п. (малюнок значно чистіший, див. `quest_image_logreg.png`),
але тренується в ~100 разів і передбачає в ~50 разів повільніше, ще й потребує GPU.
